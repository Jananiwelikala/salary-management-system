# Salary Management System

A Salary Management System developed as a university group project in 2024.

The system was designed to streamline employee salary and overtime management for a public administration environment. It was implemented as a desktop application using C# Windows Forms with MySQL for data storage.

## Features

- User authentication
- Employee details management
- Overtime management
- Employee search
- Salary and overtime calculation
- MySQL database integration
- User-friendly Windows Forms interface

## Technologies

- C#
- .NET Windows Forms
- MySQL
- Visual Studio
- Git
